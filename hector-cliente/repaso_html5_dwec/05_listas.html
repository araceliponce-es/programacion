Proceso de depuración en DevTools

  1. Abrir las herramientas de desarrollador.

    1. Reproducir el error.
    2. Inspeccionar el HTML y CSS.
    3. Revisar la consola de JavaScript.
    4. Localizar el origen del problema.
  2. Realizar los cambios necesarios.
  3. Comprobar que el error se ha solucionado.

Conceptos de JavaScript

DOM
Document Object Model. Representa la estructura de un documento HTML como un árbol de objetos que JavaScript puede consultar y modificar.
ECMAScript
Especificación que define las características y reglas del lenguaje de programación en el que se basa JavaScript.
Event Loop
Mecanismo que permite a JavaScript gestionar operaciones asíncronas y ejecutar tareas pendientes mediante la cola de eventos.
