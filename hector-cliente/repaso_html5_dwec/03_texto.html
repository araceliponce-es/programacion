Código

Para representar código dentro de un párrafo se puede utilizar <p>, mientras que <code> identifica un fragmento de código.

Por ejemplo, una variable puede declararse como const mensaje = "Hola, mundo";.

Para bloques de código que deben conservar sus saltos de línea y espacios:

<!DOCTYPE html>
<html lang="es">
    <body>
        <h1>Hola, mundo</h1>
    </body>
</html>

Citas extensas

Las citas largas pueden representarse mediante <blockquote> y su fuente puede indicarse mediante el atributo cite.

El marcado semántico permite describir el significado y la función de las distintas partes de un documento, facilitando su comprensión por navegadores, herramientas de accesibilidad y otros agentes.

La cita anterior se presenta como un bloque independiente y contiene la referencia a su fuente mediante el atributo cite.
